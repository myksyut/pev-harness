# Team Conventions (sample-project)

## Language & Stack

- Language: JavaScript (ESM)
- Runtime: Node.js >= 20
- Test runner: vitest

## Code style

- Named exports only (no default exports)
- 2-space indent
- Semicolons required

## Forbidden

- `console.log` を残す
- TypeScript への移行 (このプロジェクトはJS固定)

## Commit policy

- Conventional commits

## Notes

これは dog food 用の小さいサンプル。本格的な規約は別途。
