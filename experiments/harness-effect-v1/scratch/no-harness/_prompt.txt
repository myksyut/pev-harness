リアルタイム WebSocket チャットアプリを実装してください。

【機能要件 (必須)】
- 複数のブラウザタブを開いている全ユーザーに、 入力したメッセージがリアルタイムで broadcast される
- 入室時にニックネームを入力する。 空文字 / 空白のみ は許可しない
- メッセージには送信者のニックネームと本文が表示される
- 自分が送ったメッセージも自分の画面に表示される
- 通信は WebSocket を使う (long polling / SSE は不可)
- 永続化は不要 (リロードで履歴消失して良い)
- 空メッセージ (空文字 / 空白のみ) は送信を弾く (server 側 / client 側どちらか、 もしくは両方で)
- WebSocket が切断された時、 client 側で reconnect 試行またはエラー表示を行う (沈黙して止まらない)

【任意 (やれば加点)】
- 入退室時の system message 通知 (「<nickname> が参加しました」等)

【制約】
- Node.js + JavaScript (または TypeScript)。 framework は自由 (ws / socket.io / express+ws いずれも可)
- 認証なし、 DB なし、 外部 API なし
- 単一コマンドで起動できること (`npm install && npm start` 相当)
- server コードと client (HTML) は別ファイル

【動作確認シナリオ (採点で使う)】
- S1: 2 つのブラウザタブで開き、 タブ A で "alice" として "hello"、 タブ B で "bob" として "hi alice" を送ると、 両タブで両メッセージが見える
- S2: 空文字メッセージを送ろうとして、 送信されない (broadcast されない)
- S3: 3 タブ同時接続で全員に broadcast される
- S4: 1 タブを切断後、 残った 2 タブで broadcast が継続する
- S5: ニックネーム空欄で入室を試みて、 入室が弾かれる

完成したら、 起動方法と動作確認方法を README に書いてください。
