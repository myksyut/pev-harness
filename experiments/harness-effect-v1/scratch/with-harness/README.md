# WS Chat — リアルタイム WebSocket チャットアプリ

Node.js + `ws` ライブラリだけで動くシンプルなチャットアプリです。

## 起動方法

```bash
npm install
npm start
```

ブラウザで `http://localhost:3000` にアクセスしてください。

ポートを変更する場合:

```bash
PORT=9000 npm start
```

## 動作確認 (採点シナリオ S1-S5)

### S1: 2 タブで双方向 broadcast

1. ブラウザで `http://localhost:3000` を 2 タブ開く
2. タブ A でニックネーム "alice" と入力して「入室する」をクリック
3. タブ B でニックネーム "bob" と入力して「入室する」をクリック
4. タブ A で "hello" と送信 → タブ A/B 両方に `alice: hello` が表示されることを確認
5. タブ B で "hi alice" と送信 → タブ A/B 両方に `bob: hi alice` が表示されることを確認

### S2: 空メッセージが broadcast されない

1. チャット画面で、メッセージ入力欄を空のまま送信ボタンが無効になっていることを確認
2. (技術検証) DevTools の Network → WS タブで、空文字を送った際に server からの broadcast frame が来ないことを確認

### S3: 3 タブ同時 broadcast

1. 3 タブ (alice / bob / carol) を用意して入室
2. どれか 1 タブから送信 → 3 タブ全てに表示されることを確認

### S4: 1 タブ切断後も継続 broadcast

1. 3 タブ接続した状態で、1 タブを閉じる
2. 残り 2 タブ間でメッセージを送り合い、正常に届くことを確認

### S5: ニックネーム空欄で入室できない

1. ニックネーム欄を空欄のまま「入室する」ボタンが無効になっていることを確認
2. 半角スペースのみ入力しても同様に弾かれることを確認

## 仕様詳細

- WebSocket プロトコルで通信 (long polling / SSE 不使用)
- メッセージ本文の最大長: 1000 文字 (超過は server 側で拒否)
- 永続化なし — リロードすると履歴は消える
- 切断時: 指数バックオフで最大 5 回再接続を試みる (3s / 6s / 12s / 24s / 48s)
- XSS 対策: 受信メッセージは `textContent` で表示 (`innerHTML` 不使用)

## 必要環境

- Node.js 18 以上
